# Changelog

## v0.2.13

- Доработан отчет верификации: из CMS теперь извлекаются данные сертификата и алгоритмы подписи для embedded и detached-проверок.
- Исправлены русские строки в модуле верификации.
- Обновлены авторские метаданные и контакты: Александр Коваленко, `shurshick@bk.ru`.
- Workflow релиза переведен с устаревающего release-action на `gh release`, а `checkout` и `upload-artifact` обновлены до новых major-версий.

## v0.2.11

- Нормализована встроенная CMS-подпись перед записью в `/Contents` PDF. Это нужно для совместимости со строгими внешними валидаторами, которые принимают detached-подпись, но валят встроенный PDF из-за формата контейнера.

## v0.2.10

- Исправлена логика выходных файлов: теперь приложение всегда создаёт один итоговый PDF `*-signed.pdf`, а промежуточный `*-signed-embedded.pdf` больше не остаётся на диске.
- Режим detached упрощён: если выбран detached, создаются только `*-signed.pdf` и `*.sig`, без скрытой попытки дополнительно сделать встроенную подпись.
- Исправлен preview-редактор штампа: рамка и текст теперь не уезжают из-за ошибки координат в Qt-прямоугольнике.

## v0.2.9

- Исправлена проверка detached и встроенных PDF-подписей: вместо несуществующего ключа `csptest -content` теперь используется корректный синтаксис `-detached -in <данные> -signature <подпись>`.

## v0.2.8

- Исправлена встроенная PDF-подпись на Linux: приложение больше не вызывает `cryptcp` с несуществующим ключом `-out`, а встраивает CMS-подпись в PDF через placeholder и detached-подпись от `csptest`.
- Исправлен видимый штамп: в пакет добавлен `DejaVuSans.ttf`, поэтому русский текст в штампе больше не превращается в квадраты.
- В сборку portable-бинарника добавлены новые runtime-ассеты для подписи и кириллицы.

## v0.2.7

- Исправлен приоритет поиска утилит CryptoPro: проект теперь сначала берёт `certmgr`, `csptest`, `cryptcp` из canonical путей `/opt/cprocsp/...`, и только потом смотрит в `PATH`.

## v0.2.6

- Исправлен ещё один реальный кейс Linux/CryptoPro: сертификат теперь извлекается не только по точному имени поля `certmgr`, но и по типу значения и порядку строк в блоке сертификата.

## v0.2.5

- Исправлен реальный Linux-разбор сертификатов CryptoPro: приложение теперь корректно читает русские поля `certmgr`, умеет декодировать `utf-8`, `cp1251`, `cp866` и не теряет сертификаты, если `certmgr` пишет их в `stderr`.

## v0.2.4

- Исправлен разбор вывода `certmgr` на Linux: список сертификатов теперь читается и из `stdout`, и из `stderr`.

## v0.2.3

- Исправлен поиск сертификатов: приложение теперь читает оба хранилища CryptoPro, `uMy` и `mMy`.

## v0.2.2

- Linux-артефакты пересобраны на EL8-совместимой базе для запуска на RedOS 8 и других системах с `glibc 2.28`.
- `PySide6` зафиксирован на ветке `6.8.x`.
- Сборочные скрипты теперь принимают `PYTHON_BIN`.

## v0.2.1

- Исправлена RPM-упаковка: CryptoPro больше не нужен на этапе установки пакета.
- В DEB и RPM добавлены runtime-зависимости Qt/EGL.
- Иконка заменена на вариант из Windows-версии с прозрачным фоном.

## v0.2.0

- Добавлен полноценный редактор штампа с профилями и ручным позиционированием.
- Добавлена проверка PDF, `.sig`, `.p7s` с экспортом отчётов.
- Добавлена диагностика CryptoPro и окно "О приложении".
- Добавлен совместимый import/export JSON-настроек и профилей.
- Перепроверены Linux-артефакты и checksums.

## v0.1.0

- Первый публичный релиз Python/Qt-версии для Linux.
